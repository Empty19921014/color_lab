플레이 방법

기억 게임 · 1단계 3개부터 매 단계 하나씩 늘어납니다. 각 단계에서 새 무작위 순서를 2번 맞히면 통과합니다. 최종 6단계는 8개씩 2번! 같은 색도 연속으로 나옵니다. 숫자 1–4 또는 터치로 입력하세요.

RGB 게임 · 화면의 맞출 색을 보고 RGB를 조절해 3문제를 풀어보세요. 조절 중인 색은 무드등에 실시간으로 나오며, ‘맞출 색 바꾸기’로 현재 문제의 목표색만 바꿀 수 있습니다. 점수는 RGB 값 차이 기준이며 화면과 LED 색은 다르게 보일 수 있습니다.

전체화면 · 게임 위쪽 ‘전체화면 플레이’를 누르세요. ‘나가기’ 또는 Esc로 돌아옵니다. 지원하지 않는 브라우저에서는 화면 안을 가득 채웁니다.

무드등 연결

  1. 전원을 분리하고 micro:bit V2와 네오픽셀 4개를 P1·3V·GND에 연결하세요.
  2. MakeCode에 neopixel 확장을 추가한 뒤 다운로드한 코드를 JavaScript 탭에 넣어 설치하세요.
  3. 노트북 Chrome/Edge에서 데이터 USB 케이블을 연결하고 ‘USB 연결’을 누르세요.

별도 태블릿과 노트북 간 원격 제어는 지원하지 않습니다. 플레이 중 박수 조작은 꺼집니다.
